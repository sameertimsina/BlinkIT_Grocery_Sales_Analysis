# BlinkIT Grocery Sales Analysis

## Project Overview
This project analyzes BlinkIT grocery sales data using Python to understand product performance, outlet characteristics, and sales patterns. The analysis includes data cleaning, exploratory data analysis (EDA), data visualization, and business recommendations.

## Objectives
- Identify top- and low-performing product categories.
- Compare sales across outlet types, sizes, and location tiers.
- Examine relationships between item visibility, item weight, ratings, and sales.
- Identify opportunities to improve inventory planning and outlet performance.

## Key Findings
- The dataset contains 8,523 records.
- Total sales are approximately 1.20 million in the dataset's sales units.
- Fruits and Vegetables generated the highest sales among product categories, followed by Snack Foods.
- Supermarket Type1 recorded the highest total sales among outlet types.
- Tier 3 locations generated the highest total sales among location tiers.
- Item Visibility, Item Weight, and Rating had very weak linear correlations with Sales in this dataset.

## Business Recommendations
- Prioritize inventory planning for high-performing product categories.
- Investigate low-performing product categories and outlets.
- Compare outlet performance to identify possible operational improvements.
- Use sales trends to support inventory and promotional decisions.
